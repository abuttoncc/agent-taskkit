# 五条红线

1. **不跨层宣布。** 文档声称、鉴权成功、返回结果、业务验收分别报告。检查器 PASS 不代表内容语义正确；被测接口 FAIL 也不代表这次研究没有完成。
2. **数值可溯源。** 结论指向检查项、原始证据和来源；事实、推断、假设分开写。
3. **缺失写缺失。** 未返回数据不补猜；“没找到”不改成“不适用”。
4. **不覆盖旧结果。** 基线、观测、对账和已交付报告按轮次新增。改范围引用前版，保留旧 FAIL；README 可更新为当前入口。
5. **凭证不入产物。** 请求日志先脱敏。路径排除规则不是凭证扫描器，普通 JSON 也可能包含 token，保存前由采集者检查。
