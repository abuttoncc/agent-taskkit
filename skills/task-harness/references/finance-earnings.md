# 财报分析场景卡

适用：财报发布后的变化分析、业绩质量与预期差。若用户做财报前准备，只能使用当时可得的信息与显式预测；不得把后来发布的实际结果写入当时的判断。

先核验财报发布日期、报告期、是否审计/重述、会计口径与财年。单季度与累计值分开；只有累计口径可比时才用相邻期间相减得到单季，并保存推导。同比周期要一致，不能把三个月与九个月直接比较。

按顺序回答：

- 收入、利润、现金流和关键经营指标发生了什么变化？分清一次性、非现金、汇率和并购因素。
- 管理层指引有什么变化？记录原话出处、区间与时间，不把意向当承诺。
- 若有可验证的事前一致预期，实际与预期的统计口径是否相同？“超预期”要有独立于实际结果的事前记录。没有预期只做同比、环比和指引对照。
- 变化支持或推翻了哪些原假设？下次用什么指标继续验证？

交付包含实际/对照表、主要变化、利润质量、解释与反证、未解决问题。增长基期为零或负数时写绝对变化、亏损收窄或扭亏，不强报同比百分比。

可选验收项：期间和比较基准明确；收入/利润变化与来源匹配；预期形成日期可查；现金与利润差异有解释；一次性项目和重述影响没有被隐藏。
